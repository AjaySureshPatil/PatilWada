
# PatilWada
The PatilWada  is a web application developed using React.js, Tailwind CSS, and Swiggy's API.  It is inspired by swiggy a well-known online food delivery platform. This project was created as part of the coursework for the "Namaste React" course.

Below, I am attaching a video to show how it looks.


## Features

- Shimmer UI.
- Search food.
- Search top rated restaurants.
- Online/offline status.
- Accordion.
- Add to cart.
- Clear cart.


## Tech

- React.js
- Parcel
- Tailwind CSS
- Redux-toolkit
- Jest(Testing)
